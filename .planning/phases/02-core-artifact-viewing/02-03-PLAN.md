<objective>
Fix the file browser sidebar being empty in the Electron renderer (tests 2 & 7 in UAT.md).

**Root cause:** `useFileBrowser.ts` calls `process.cwd()` in the renderer process. With Electron's contextIsolation, this returns the app resource path (e.g., `out/renderer/`) rather than the user's project directory. The fallback to `/home` also succeeds but shows the wrong directory.

**Fix:** Add an `app:getCwd` IPC channel that returns `process.cwd()` from the main process (where it IS correct), wire it through the preload bridge, and update `useFileBrowser.ts` to call `electronAPI.app.getCwd()` instead of `process.cwd()`.

**Purpose:** Unblock the 9 UAT tests that are blocked_by: "File browser empty — no files to click" (tests 3, 4, 6, 8, 9, 10, 11, 12, 13) plus the 2 major issues (tests 2 & 7).
**Output:** File browser sidebar populates with the user's project directory on app launch.
</objective>
